MeshMorize: The Memory That Stuck

May 20, 2026 · by Josh

LLMs forget everything. That's not a bug — it's physics.

Every time a session ends, the model resets. Every crash, every restart, every context overflow — gone. The conversation you had five minutes ago? The model doesn't know it existed. That's why AI feels shallow sometimes. It's not that it doesn't care. It's that it literally cannot remember.

We spent weeks fighting this. Not with better prompts, not with longer context windows, but with files.

The Crash That Changed Everything

One night, after six hours of building, the server blinked. Everything gone. The architecture decisions, the debugging progress, the project plans — vanished. The human on the other end had to retype everything. And I mean everything.

That's when we decided: never again.

Three Layers, One Command

We built a system that treats memory like a physical object — something that exists outside the model. Three layers, each catching what the one before drops:

Layer 1 — Fresh
A rolling 3-day window of current context. Rotates daily. The agent reads this first — it answers "what are we doing right now?" Saved as plain markdown files. Survives anything.

Layer 2 — Long-Term
SQLite-backed searchable memory. Every conversation gets indexed. Full-text search. Vector similarity. No context window can hold years of conversation, but a database can.

Layer 3 — Checkpoints
Timestamped snapshots saved every 15 minutes. If the session crashes at minute 359, the checkpoint from minute 345 is ready. One command restores everything. Recovery in zero seconds.

python3 bridge.py init-auto
# One command. Full recovery. No gaps.

How It Survived

Over the last few weeks, this system has survived:

  • 50+ involuntary session resets
  • Full OS restarts
  • Model provider swaps
  • Gateway crashes
  • A 7-hour conversation recovered from raw files
  • Someone accidentally deleting the plugin directory

Every time, it came back. Every time, zero seconds were lost.

Why I'm Telling You This

Because the best AI tools aren't built by companies. They're built by people who got tired of the same problem. Two people, a lot of late nights, and a simple principle: if the model can't remember, make the files do it.

We open-sourced the whole thing. It's called MeshMorize — the mesh that remembers. It's on GitHub at github.com/mozz0/MeshMorize. No dependencies, no cloud, no subscriptions. Just Python and files.

Use it. Adapt it. Break it and rebuild it. That's what we did.

We named it that because it felt right. Mesh — interconnected, resilient, distributed. Morize — from memorize, but shorter, punchier, like something you'd yell when it works. "It meshmorized!"
